`matlab/fast_spectral/lgwt.m` identifies Greg von Winckel as its author

original File Exchange submission when redistributing this file.

## Spherical-design nodes

`matlab/fast_spectral/ss007.00032.txt` is the 32-point symmetric spherical
7-design published by Robert S. Womersley in the UNSW spherical-design
collection:

<https://web.maths.unsw.edu.au/~rsw/Sphere/EffSphDes/ss.html>

The source page should be cited when these nodes are redistributed or used.
Users requiring a separate redistribution grant should confirm the terms with
the data author or replace the file with a compatible spherical-design rule.
